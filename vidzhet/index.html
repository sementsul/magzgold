Виджет для сайта

Бесплатный виджет красивых номеров для вашего сайта — с фильтрами по категории, цене и окончанию. Посетитель сам подбирает номер, а оформление ведёт на MagzGold. Данные грузятся в браузере посетителя — ваш сервер не нагружается.

Как встроить

Вставьте этот код в HTML страницы, где нужен блок с номерами:

<div class="magzgold-widget" data-count="6"></div>
<script src="https://magzgold.ru/widget.js" async></script>

Настройки (атрибуты data-*)

  • data-count — сколько номеров показывать за раз (1–48, по умолчанию 6; есть «Показать ещё»).
  • data-cat — стартовая категория: brilliant, platinum, gold, silver, bronze (по умолчанию — все, пользователь переключает сам).
  • data-controls — off, чтобы скрыть фильтры и показывать просто список.
  • data-title — свой заголовок над блоком.

Встроенные фильтры: категория (кнопки), цена тарифа (список), поиск по цифрам/окончанию. Можно поставить несколько блоков на одной странице.

Живой пример

Клик по «Забронировать» открывает страницу номера на MagzGold, где посетитель завершает бронь у оператора. Стили виджета самодостаточны и не конфликтуют с вашим сайтом.
